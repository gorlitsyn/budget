# Roadmap

## Этапы

1. **Каркас и деплой** — passkeys, инвайты с правами по разделам, PWA, деплой, бэкап. ✅
2. **Покупки** ✅ — общий список, живые обновления у всех (SSE), работа без связи (очередь изменений),
   автодополнение по прошлым покупкам, кто добавил / кто отметил. Несколько списков.
   Не сделано: порядок позиций вручную, группы по отделам магазина, push о новых позициях.
3. **Траты и поступления по месяцам; План** ✅ — экран по месяцам, фильтр по категории, категории с
   подкатегориями, ежемесячный план со статьями. Не сделано: офлайн-ввод трат, порядок категорий вручную.
4. **Сводка** ✅ — итоги месяца, остаток с переносом и начальным остатком, план-факт, траты по категориям,
   динамика за полгода. План прошедших месяцев зафиксирован.
5. **Публикация на GitHub** — репозиторий без данных конкретной установки, README, лицензия AGPL-3.0, чистая
   история. Установка для других: скачать проект с GitHub и развернуть у себя по README. Отдельной версии
   «только телефон» с хранением в облаке не делаем.

## Бэклог

- **Продумать раздел «Сводка».** Без доступа к «Поступлениям» она показывает только расходы и по сути повторяет
  «Операции». По умолчанию при приглашении не выдаётся.
- **MCP и iOS Shortcut** — быстрый ввод трат. Отложено.

Потом: предстоящие платежи (опциональное окно), push-напоминания, импорт выписок, калькулятор gross/НДФЛ.

## Решения по продукту

- **Без периодов** внутри месяца — только месяц целиком.
- **Без типов трат** — только категории.
- **Подкатегории — один уровень**; если у категории они есть, при вводе траты подкатегория обязательна.
- **Шаблон категорий** нового пользователя: Продукты, Бытовые, Авто, Коммуналка, Связь/Интернет.
  Пользователь удаляет, добавляет и переименовывает.
- Виды поступлений — у каждого свои; базовые: Зарплата, Аванс, Кэшбек, Прочее.
- Статья плана — одна категория, выбор из списка. **В плане только известные ежемесячные траты**: остальные
  категории живут в тратах и считаются «вне плана». План — ориентир, отступать от него можно.
- **Правка плана не меняет прошедшие месяцы**: их план и перерасход остаются такими, какими были.
- Пользователи изолированы; доступ — инвайтом с правами по разделам (нет / смотреть / править).
- Учёт по картам/счетам не ведём.
- Фронт на Vue.
