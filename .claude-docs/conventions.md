# Conventions

- Интерфейс, сообщения об ошибках API и комментарии — по-русски. Идентификаторы — по-английски.
- Время — миллисекунды UTC (`Date.now()`) в INTEGER. id — случайные base64url (`newId()`).
- Входные данные API — zod-схема (общие — в `packages/shared`). Ошибка — `throw new HttpError(status, 'текст')`,
  текст показывается пользователю как есть.
- SQL — только в `store.ts` (или в отдельном `store-<раздел>.ts` для новых разделов), подготовленные запросы.
- Миграции: новая строка в конец `MIGRATIONS`; выпущенные не править.
- Тесты API — через `app.inject` с `Client` из `test/helpers.ts` (банка cookie, Origin, программный passkey).
- Импорты внутри пакетов — с расширением `.ts`.
- Коммиты — по-русски, повелительное наклонение («Добавь список покупок»).
